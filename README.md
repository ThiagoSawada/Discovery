# DevLinks - Rocketseat Discover

O DevLinks é um agregador de links para usar como cartão de visitas online, permitindo reunir suas principais redes sociais e links de contato em uma única página responsiva.

## 🚀 Tecnologias

Esse projeto foi desenvolvido com as seguintes tecnologias:

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## 💻 Projeto

O projeto conta com:
- Layout responsivo (adaptável para dispositivos móveis e desktop);
- Alternância de tema claro (light mode) e escuro (dark mode);
- Animações e transições via CSS;
- Modificação dinâmica do DOM via JavaScript.
